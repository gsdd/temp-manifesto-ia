Component library

The reusable blocks every page is built from. One name, one shape, one interaction type per component. The sidebar on each page lists which of these it uses, by the same names.

How to read this library

Seven interaction types. If a rectangle cannot be named from this library, it is a random box and should not be on a page.

  • Band. A full-width block that composes other components: Hero, Closing CTA band. Bleeds to the edge with a rule top and bottom.
  • SendButton. An action: Send, Accept, Clear filters, Search, header Contact, the primary of a CTA pair. Heavy 2px ink frame, light fill, verb only. Never a content-page link except header Contact.
  • See our workText link. Navigate: See our work, All thinking, situations, breadcrumbs, footer, mega-nav strands, pagination. Underlined or plain text, never a box.
  • TitleSupport lineCard. Whole unit is a hit area to one destination page. Solid 1px box. Title plus support line. Seven card types, one shape each.
  • LoyaltyPricingTag. Small linked label. One dimension, max three. Squared corners, quiet border. Not a filter.
  • AllLoyaltyFilter. Toggle on a listing. Pill-shaped button, not a link. Selected uses a heavier border.
  • MetricProseStatic. Not clickable. Dashed box or plain text: logos, metrics, CIVD, form fields, video, quote, empty message, prose.

Do not mix

  • A Filter is not a Tag. Tags navigate. Filters toggle.
  • A Tag is not a Button. Do not put tags in the header.
  • A Triangle tile is not an Offer card. Pillar versus buyable service.
  • A Theme card and a Role card are outline cards. An Offer card has the grey fill. An Article card has neither fill nor image.
  • A CIVD cell is not a Card. The cells are a static diagram.
  • A Metric box is not a Card. Numbers are not destinations.
  • A listing link is not a Case card. Home All work is a Text link. Only real cases wear the Case card.
  • The sidebar on each page is annotation for this wireframe. Nothing in it is a live component.
