Page modules

Named units used on this wireframe. Each unit has one interaction type. Working notes are not shown here.

How to read these units

Six types. If a rectangle cannot be named from this list, it is a random box.

  • Button An action: Send, Accept, Clear filters, Search submit, header Contact. Outlined control. Never a content-page link except header Contact.
  • Text link Navigate: See our work, All thinking, situations, breadcrumbs, footer, mega-nav strands.
  • Card Whole unit is a hit area to one destination page. Solid box. Title plus support line.
  • Tag Small linked label. One dimension, max three. Not a filter.
  • Filter Toggle on a listing. Button, not a link. Selected uses .on.
  • Static Not clickable. Dashed box: logos, metrics, CIVD, form fields, video, empty message.

Do not mix

  • A Filter is not a Tag. Tags navigate. Filters toggle.
  • A Tag is not a Button. Do not put tags in the header.
  • A Triangle tile is not a Service card. Pillar versus buyable service.
  • A CIVD cell is not a Card. The cells are a static diagram.
  • A Metric box is not a Card. Numbers are not destinations.
  • A listing link is not a Case card. Home All work is a Text link. Do not invent a case called More work.
  • Do not call live units chips. Sidebar working notes are annotations.
