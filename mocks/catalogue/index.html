Page modules

Named units used on this wireframe. One type, one shape. Working notes are not shown here.

How to read these units

Filled rectangle is a primary button (the action). Underline with no box is a text link (the secondary path). Pill is a filter. Dashed small label is a page tag. Numbered square is pagination. Grey-fill card is an offer (a buyable service). Image card is a case. Portrait stub is a report. White text card is an article, a theme, or a role: the label on the unit tells you which. Circle avatar is a person. Heavy three-up panels are the triangle, not offer cards. Four named cells are CIVD, not metrics.
